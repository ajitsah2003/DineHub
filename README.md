# DineHub
DineHub is a modern restaurant discovery and food ordering web application built with MERN STACK, and modern web technologies. It provides an elegant UI, responsive design, restaurant listings, menu browsing, and a seamless online dining experience.
# 🍽️ DineHub

> A modern restaurant discovery and table reservation platform built with Next.js, React, Tailwind CSS, and modern web technologies.

![DineHub Banner](./public/banner.png)

## 📖 Overview

DineHub is a premium restaurant booking and discovery platform that allows users to explore restaurants, browse menus, reserve tables, and enjoy a seamless dining experience. The platform features a modern, responsive interface designed for both customers and restaurant owners.

Whether users are searching for fine dining, family restaurants, cafes, or luxury hotels, DineHub provides an intuitive experience with fast navigation, beautiful UI, and smooth booking functionality.

## ✨ Features

- 🔍 Search restaurants by name or category
- 🍽️ Browse restaurant details and menus
- 📅 Book tables online
- ⭐ Restaurant ratings and reviews
- ❤️ Save favorite restaurants
- 📱 Fully responsive design
- 🌙 Modern and elegant UI
- ⚡ Fast performance with Next.js
- 🔐 User Authentication
- 👤 User Profile Management
- 📍 Location-based restaurant listings
- 📸 High-quality restaurant galleries

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/your-username/DineHub.git
```

### Navigate into Project

```bash
cd DineHub
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:3000
```
